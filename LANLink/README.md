# LANLink Next — офлайн чат и обмен файлами

Один компьютер запускает сервер на Python 3.10+, другие заходят через браузер по локальному IP. Интернет, npm и pip не нужны. Приложение хранит аккаунты, сообщения и файлы на компьютере сервера.

## Запуск новой установки

1. Распакуйте `LANLink-Next.zip` на компьютер с установленным Python.
2. Запустите `start.bat` в папке `LANLink-Next` (или `py -3 server.py` в PowerShell).
3. Откройте `http://localhost:8000`. Для других компьютеров и телефонов той же сети используйте адрес LAN из окна сервера.
4. Администратор **уже создан**. Войдите под логином `admin999@local` и паролем, который был согласован при создании проекта. Повторная регистрация после перезапуска не нужна.
5. Для обычных участников выберите «Регистрация»: код сети выводится в окне сервера и лежит в `storage/config.json`.

Новая база в архиве содержит только учётную запись администратора. В ней нет сообщений, файлов и пользователей из вашего присланного архива. Настройте пароль администратора заново перед использованием в более широкой сети.

## Обновление вашей прежней установки без потери истории

1. Остановите прежний сервер сочетанием Ctrl+C. Сделайте копию прежней папки `storage` целиком.
2. Распакуйте новую версию **в отдельную папку**. Скопируйте из неё `server.py`, `moderation.py` и папку `web` в прежнюю папку проекта. Не заменяйте вашу старую папку `storage` новой из архива.
3. В прежней папке откройте PowerShell и выполните:

```powershell
py -3 server.py --set-admin admin999@local
```

4. Введите согласованный пароль дважды в приглашениях. Пароль не будет отображаться в окне. Команда создаст администратора, если его нет, или обновит его пароль. Другие администраторы получат обычную роль; существующие пользователи и история сохранятся.
5. Запустите `start.bat`. Переход базы данных на новую структуру выполнится автоматически.

Если пароль нужно сменить позже, снова остановите сервер и выполните ту же команду с новым паролем. Это также завершит прежние сеансы администратора.

## Возможности

- Общий чат и личные сообщения, изменение и удаление своих сообщений.
- Фото профиля в сообщениях и списке людей: нажмите на круглый аватар рядом со своим именем, чтобы загрузить PNG, JPEG или WebP до 2 МБ. Если фото нет, показываются инициалы.
- Создание комнат, изменение и удаление сообщений, а также блокировка отправки выполняются в окнах самого LANLink.
- Администратор может изменять и удалять сообщения общего чата, блокировать отправку на 5–60 минут, просматривать журнал действий и скачивать резервную копию.
- Открытые комнаты: нажмите `+`, чтобы создать, или «Найти комнату», чтобы присоединиться. Участники комнаты видят её сообщения и файлы. Комнаты доступны всем зарегистрированным пользователям для вступления.
- Счётчики непрочитанного после первого посещения, поиск по тексту и названиям файлов в выбранной беседе, подгрузка старой истории по 50 сообщений.
- Передача файла до 50 МБ с отображением прогресса. Файлы личной беседы доступны только двоим, файлы комнаты — её участникам.
- Новый дизайн: список бесед, переписка и сведения с файлами на широком экране; отдельные экраны списка и чата на телефоне.
- Сервер скрывает слова из списка цензуры звёздочками в новых и изменённых сообщениях и названиях файлов. В названиях комнат такие слова не допускаются.

## Цензура и управление словами

Администратор открывает кнопку «Список цензуры», вводит новое слово и нажимает «Добавить». Слово с `*` в конце охватывает его окончания: например, `пример*` относится и к `примеры`. Для удаления нажмите на слово в списке. Изменения применяются сразу и записываются в журнал администратора.

Начальный список хранится в `storage/censorship.json`. Его можно изменить через интерфейс; файл сохраняется вместе с резервной копией. Цензура действует на новые отправки и правки, но не переписывает старую историю задним числом. Автоматический фильтр может не распознать каждое намеренное искажение слова; администратор по-прежнему может удалять сообщения и блокировать отправку.

## Как устроено хранение

`storage/lanlink.sqlite` — база; `storage/files/` — загруженные файлы; `storage/avatars/` — фото профилей; `storage/config.json` — код регистрации; `storage/censorship.json` — фильтр слов. Админ-кнопка «Скачать резервную копию» выдаёт ZIP с базой SQLite, кодом регистрации, фильтром, файлами и аватарами. Храните эту копию в надёжном месте: она содержит всю переписку и хеши паролей. Для восстановления остановите сервер, скопируйте содержимое папки `storage` из копии в проект и запустите сервер. Если архив сохранился на другом компьютере, восстановление возможно без интернета.

Код регистрации можно изменить в `storage/config.json` при выключенном сервере. Изменение кода не отключает уже зарегистрированные аккаунты. Поиск ограничен первыми 50 совпадениями, журнал — последними 100 записями. Уведомления и счётчики обновляются примерно раз в две секунды. Файлы в архиве резервной копии формируются в памяти сервера, поэтому для очень больших хранилищ лучше копировать `storage` при выключенном сервере.

HTTP в локальной сети не шифрует пароль и сообщения. Используйте доверенную сеть; для более чувствительного применения потребуется HTTPS с локальным сертификатом. Не выкладывайте папку `storage` или резервные копии в общий доступ.

## Проверка

```powershell
py -3 -m unittest discover -s tests -v
```

Тесты создают временное хранилище и проверяют регистрацию, права доступа, чат, комнаты, передачу файлов, поиск, цензуру, блокировку, журнал, резервную копию и сохранение данных. Чтобы открыть проект на другом устройстве, проверьте локальный IP через `ipconfig` и разрешите Python в брандмауэре для частной сети; гостевой Wi-Fi может изолировать клиентов.
